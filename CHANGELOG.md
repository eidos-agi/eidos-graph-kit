## [0.1.0] - 2026-05-05

### Added
- Initial public release of the deterministic graph layout and SVG rendering toolkit.
- Pipeline, hub-spoke, and fan-in layout modes.
- Geometry diagnostics for missing nodes, cycles, back-edges, long edges, fan-in pressure, node overlap, and edge overlap.
- Static SVG rendering with optional sections, icons, popover metadata, and obstacle-aware edge routing.
- Public-safe review harness and synthetic examples.
